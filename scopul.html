Scopul regresiei liniare

Scopul regresiei liniare este să găsească o linie dreaptă care minimizează eroarea dintre punctele de date observate și valorile prezise de model. Odată găsită dreapta, o putem folosi pentru a estima valoarea etichetei pentru o intrare nouă. Terminologia folosită în lucrare:

  • features (caracteristici, variabile independente) – datele de intrare, notate x;
  • label (țintă, variabilă dependentă) – valoarea de prezis, notată y;
  • predicție – valoarea calculată de model, notată ŷ;
  • parametri (θ sau β) – numerele pe care modelul le învață din date;
  • set de antrenare / set de test – datele cu care învață modelul, respectiv datele cu care îi verificăm calitatea pe exemple noi.
