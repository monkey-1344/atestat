Tipuri de regresie liniară

Regresia liniară simplă se folosește când prezicem valoarea țintă cu o singură caracteristică de intrare, presupunând o relație liniară între cele două:

y = θ0 + θ1 · x

θ0 este termenul liber (valoarea lui y când x = 0), iar θ1 este panta dreptei (cu cât se modifică y când x crește cu 1). În unele surse parametrii se notează β0 și β1.

Regresia liniară multiplă folosește mai multe caracteristici:

y = θ0 + θ1 · x1 + θ2 · x2 + … + θn · xn

Pentru două caracteristici graficul este un plan, iar pentru mai multe un hiperplan. În formă matriceală, ŷ = Xθ, unde X este matricea datelor (cu o coloană de 1 pentru termenul liber), iar θ este vectorul parametrilor.
